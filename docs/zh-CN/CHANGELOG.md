# 变更记录

本插件版本与 tag 独立于伴随插件。此文不宣布公开发布。

## 未发布

### 新增（Added）

- 一张 Antigravity 卡显示两个 CLI 桶的四行剩余额度、重置倒计时及 Claude/GPT 共用桶仅显示说明。ACP 派活保护与契约快照保持独立。
- 可选 antigravity-cli 展示本机 agy `/usage` 表。默认关闭；未证明与 Paseo ACP 是同一额度池时，不把它用于 ACP 派活。随附读取不建立这个证明。
- Experimental 插件源码、独立 Node 命令及英文/简体中文界面。
- 上手、工作流、数据、兼容、人工发布文档。
- Bug/功能/兼容报告模板与私下安全披露指引。

### 变更（Changed）

- 尚无已发布基线。

### 修复（Fixed）

- 显式计划 `onlyRoles` 现在会保留到 usage 归一化、RPC 输出和额度/派活发布。只有 `role` 或 `candidateFor` 在列表中的档案可派；进度线及额度保护覆盖不能放宽列表。现有带日期的审查例外保持独立，并与显式限制取交集。
- agy 非零退出或被信号终止时，即使 stdout 有合法行也丢弃；只有正常 code 0 读取能提供新的实时样本。

- antigravity-cli 计划在读取开关关闭或未设置时仍保留未知 ACP 停派。手填百分比不能替换这行。过期的 agy 表按过期样本展示。

### 安全（Security）

- 本机隐私、身份、历史泄漏、包内容闸必做。
- 所有者须发版前启用私下漏洞报告。

### 注意（Notes）

- 初始包版本计划 0.1.0，experimental、未发布。
- Paseo >=0.11.0 <0.12.0；完整平台/桌面认证未完成。
- fleet-quota/v1，兼容新增 contractVersion 为 1.2.0；本文档修改不变更契约或迁移数据。
- 最低伴随发布版本未建立，不声明已支持版本对。
- 实测伴随 tag/提交、升级顺序须每次发版互通验证后登记，不由包同号推断。
- 发版前须 Git 安装、包、桌面、首卡、回退证据，见 RELEASE；代码回退不撤销数据写入。
